推荐合作最容易在介绍完成后出问题：一个人记得承诺了比例，另一个人记得是折扣，没人定义费用适用于首笔、实收款、续费、退款还是关联公司。

解决办法不是设计复杂佣金系统，而是一份把资格、归因、付款和披露写清的短协议。

## 介绍费协议检查表

| 条款 | 需要决定什么 |
|---|---|
| 有效推荐 | 需要提供哪些信息与同意？ |
| 排除项 | 现有管道、历史联系人、受限客户 |
| 归因窗口 | 介绍后多久内可以获得费用？ |
| 费用基数 | 固定金额、比例、毛利或实收收入 |
| 付款事件 | 签约、开票、到账还是里程碑 |
| 调整 | 退款、拒付、取消、税费、抵扣 |
| 未来收入 | 续费、增购、关联主体 |
| 行为 | 可使用的表述、隐私、反垃圾、品牌 |
| 披露 | 财务关系何时必须可见 |
| 记录 | 证据、报表、发票与争议流程 |
| 终止 | 已推荐客户、存续条款、尾款 |

## 1. 定义什么叫有效推荐

一次有效介绍应识别潜在客户、确认对方同意被连接，并提供足够背景，让后续沟通相关。要明确姓名、邮箱、会议或完成 discovery 中哪一步才算有效。

排除已经在销售管道里，或在规定回溯期内联系过的客户，否则同一个机会可能被多人认领。

## 2. 区分介绍与销售工作

简单介绍、主动筛选、联合销售、内容推广、活动交付和客户管理，是不同贡献。费用与责任要对应实际工作。

如果推荐人需要公开描述服务，要规定可使用的事实和证据，不能为误导性背书或隐藏压力付费。

## 3. 明确费用基数与付款事件

可以是固定金额、首笔实收款比例、指定项目收入分成，或单独定价的交付角色。要写清税费、报销、折扣、退款和拒付是否计入。

Iris 在部分历史顾问合作中使用过统一 10%，因为容易解释，也让大部分收入留给实际交付方。这是第一方经验，不是市场标准。利润、参与程度、监管与风险都可能得出不同答案。

## 4. 写归因窗口

明确归因何时开始、持续多久、客户几个月后购买另一项服务怎么办，也要处理续费、增购、关联公司与多个推荐人。

不是要预测所有边缘情况，而是避免最值钱的情况只靠记忆。

## 5. 处理披露与禁止行为

美国 FTC 指出，如果一项重要关系可能影响受众如何评价背书，可能需要清晰披露。涉及美国消费者的公开推广时，应查阅 FTC 的 [Endorsement Guides](https://www.ftc.gov/news-events/topics/truth-advertising/advertisement-endorsements)。

其他地区、行业、专业服务、公共采购、金融、医疗、雇佣或经纪活动可能有不同限制，必须获得当地专业意见。

## 6. 保护客户信任与数据

没有合适法律基础与同意，不要转移个人信息。写清推荐人可以分享什么、记录存在哪里、保存多久、谁处理删除或访问请求。

除非明确授权，推荐人不能承诺价格、结果、档期或合同条款。
